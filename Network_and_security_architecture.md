My network will be split into two segments, admin and User network, as well as have a security monitoring network.

The admin network, as previously discussed, will only be accessible via the doctor and contain all patient records within the clinic. The Doctor will also be held responsible for granting nurse clearance once hired. The network will have the file sharing server and the doctor's own workstation within it. It is imperative that nobody else be able to access this segment of the network without knowledge, approval, and oversight by the doctor.

The User network will contain the remaining workstations, Nurses and HR, and consist of the file sharing server, four workstations, and a switch to connect them all to the server. All employees, including the doctor, should be able to access this segment of the network. This segment should not be able to change admin level settings and restrictions.

The security monitoring network could be oversighted by a third-party IT company, to monitor threats. Files should be kept hidden to them, but access to them should be visible. An external, secure connection to the server should be the only thing that is in this segment.
