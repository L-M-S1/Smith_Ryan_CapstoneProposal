My network will utilize windows workstations as windows is a more common, and sometimes easier to understand OS than Linux.

I will be making use of an authentication service, as I need to ensure only authorized users can access patient records. 

File services will also be implemented to allow the nurses to share files with the doctor and be able to communicate suggested actions. 

A switch will be used to connect all workstations to a shared file server, allowing ease of access to files instead of requiring Nurses to email files or print them out.
